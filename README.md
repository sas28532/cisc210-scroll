This repository contains the starter files for the Pi Scrolling Display project.
It includes:
A working display.c with open/close functions and a partial display_letter
A Makefile to build the project
Header files scroll.h and display.h
Stubs for input.c
A main.c that demonstrates display_letter functionality

To compile:
make
To run:
make run
To clean:
make clean
